# Vishal Sarser — Portfolio

Responsive animated portfolio built with HTML, CSS and JavaScript.

## Hosting

Published with GitHub Pages from the main branch, repository root. All asset paths are relative so the site works under a repository path.

## Editing

Update index.html for content, style.css for appearance, and app.js for interactions. The portrait and downloadable resume are included in the repository root.

Animations respect reduced-motion preferences.
